🧭 What Code Do I Need for My Product? (Customer Decision Guide)

Choosing the right barcode format depends on where your product is sold, the packaging substrate, and scanner infrastructure:

👉 Labeling warehouse shelves, bins, and pallets?

Code 128 is the industry gold standard for warehouse management systems (WMS) and internal logistics.

👉 Tracking company IT assets, tools, or serialized parts?

Use Code 128 to encode alphanumeric serial numbers (e.g. LAPTOP-2026-X8) onto durable sticker labels.

👉 Can I use Code 128 at a grocery store checkout?

Standard supermarket cash registers expect 12-digit UPC or 13-digit EAN; use Code 128 for logistics, shipping, and internal operations.

⚖️ Legal & Compliance Guide

Code 128 Usage Guidelines & Quiet Zone Rules

  • ⚠ Code 128 is an open public-domain standard (ISO/IEC 15417). No royalties or company prefix registrations are required for private or internal use.
  • ⚠ When using GS1-128 (formerly UCC/EAN-128) in commercial freight, you must format data with official GS1 Application Identifiers (AIs) and start with an FNC1 character.
  • ⚠ Ensure a minimum quiet zone of 10 times the module width (10X) on both ends of the barcode to allow laser scanners to synchronize timing.

Frequently Asked Questions

What characters can I encode into a Code 128 barcode? ▼

Code 128 can encode all 128 standard ASCII characters, including uppercase letters, lowercase letters, numbers, punctuation symbols, and control codes.

Does your engine use Code 128 subset C for numeric data? ▼

Yes. Our engine uses automatic optimization to switch into Code 128C whenever strings of digits appear, compressing two numeric digits into a single barcode character for maximum compactness.
