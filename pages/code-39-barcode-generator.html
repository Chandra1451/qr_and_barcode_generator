What Code Do I Need for My Product? (Customer Decision Guide)

Choosing the right barcode format depends on where your product is sold, the packaging substrate, and scanner infrastructure:

When should I choose Code 39 over Code 128?

Choose Code 39 when encoding shorter alphanumeric IDs (like ASSET-104) where legacy scanners or government contracts (MIL-STD-129) require it. Choose Code 128 if you have longer strings or space constraints on small labels.

Should I enable the Modulo-43 check digit?

Enable Mod-43 if you are tracking high-value assets, medical specimens, or defense shipments. For casual office inventory, standard Code 39 without check digit is scannable on all hardware.

Legal & Compliance Guide

Code 39 Technical Standards & Quiet Zone Rules

  • Code 39 requires a minimum quiet zone (blank white margin) of 10 times the narrow bar width on both the left and right sides.
  • Standard Code 39 is not case-sensitive; lowercase letters are automatically capitalized upon encoding.
  • Ensure start and stop asterisks (*) are preserved in the optical pattern to allow bi-directional scanning.

Frequently Asked Questions

What characters can be encoded in a standard Code 39 barcode? ▼

Standard Code 39 natively encodes 43 individual characters: 10 numeric digits (0–9), 26 uppercase English letters (A–Z), and seven punctuation and mathematical symbols: hyphen (-), period (.), space ( ), dollar sign ($), slash (/), plus (+), and percent (%). Lowercase letters entered into standard mode are automatically capitalized. For full ASCII support including lowercase letters and control characters, Full ASCII Extended Code 39 combines these standard symbols in pairs.

What is the difference between Code 39 and Code 128? ▼

Code 39 is a discrete symbology where each character is separated by an inter-character gap, making it simpler, highly resilient, and decodable by virtually all legacy barcode readers without specialized software. However, Code 39 requires significantly more physical horizontal space per character. Code 128 is a continuous, high-density symbology that encodes the entire 128 ASCII table in approximately half the horizontal width and features dynamic numeric compaction (Subset C). For compact spaces, choose Code 128; for legacy defense, automotive, or simple asset tracking, choose Code 39.

Why do Code 39 barcodes have asterisks (*) at the beginning and end? ▼

The asterisk (*) character is the designated start and stop delimiter in the Code 39 specification. It tells optical barcode scanners which direction the beam is reading across the bars (left-to-right or right-to-left) so the decoder can orient the payload accurately. In modern scanners, the asterisks are stripped automatically and are not transmitted to your inventory database or spreadsheet.

How is the optional Modulo-43 check digit calculated for Code 39? ▼

Code 39 has built-in self-checking properties due to its fixed pattern ratio (each character contains 9 elements: 3 wide and 6 narrow). However, high-reliability applications (such as DoD LOGMARS or healthcare asset tracking) add a Modulo-43 check character: each character in the payload is assigned a numerical value from 0 to 42, all values are summed, the sum is divided by 43, and the remainder maps back to the corresponding check character appended to the end of the data.
