Frequently Asked Questions

What is the finder pattern on a Data Matrix code? ▼

A Data Matrix code features an "L" shaped solid line on two adjacent sides, which cameras use to determine the orientation and module size of the symbol.

Can Data Matrix codes be read if partially scratched or damaged? ▼

Yes! The ECC 200 specification utilizes Reed-Solomon error correction algorithms capable of recovering up to 30% of obscured or scratched modules.
