QR Code (Quick Response)

ISO/IEC 18004 • 2D Matrix
⚡ Generate in Studio

Originally created in 1994 by Denso Wave, QR Code is the world's most ubiquitous 2D matrix barcode. It utilizes three distinctive square finder patterns positioned in three corners, enabling omnidirectional 360-degree scanning at high velocity.

Max Numeric Data
7,089 Digits
Max Alphanumeric
4,296 Characters
Max Binary (Bytes)
2,953 Bytes
Error Correction
L (7%), M (15%), Q (25%), H (30%)

Logo Embedding Best Practice: When placing a custom brand logo or icon into the center of a QR code, always enforce Error Correction Level H (30% redundancy). This ensures the scanner can reconstruct the obscured central data modules without any scanning failure.

⬛

Data Matrix (ECC 200)

ISO/IEC 16022 • 2D Industrial Matrix
⚡ Generate in Studio

Data Matrix ECC 200 features an "L-shaped" solid alignment finder pattern on two adjacent borders and alternating dark/light timing cells on the opposite edges. It offers the highest information density per square millimeter of any 2D code.

Aspect Ratio
Strict 1:1 Square (or Rect.)
Max Alphanumeric
2,335 Characters
Primary Industries
Aerospace, Automotive, PCB, Pharma
Quiet Zone
1 Module Width

Widely mandated by the US Department of Defense (MIL-STD-130 UID) and global pharmaceutical serialization standards (GS1 DataMatrix) for direct part marking (DPM) via laser etching and dot peen.

🎯

Aztec Code

ISO/IEC 24778 • 2D Concentric Matrix
⚡ Generate in Studio

Invented in 1995 by Welchn Allyn, Aztec Code is defined by a single concentric square "bullseye" finder pattern located in the exact physical center of the code. Data modules spiral outwards from the core.

Quiet Zone
Zero (None Required)
Max Alphanumeric
3,067 Characters
Key Advantage
Zero margin allows tight borders
Primary Industry
Aviation (IATA), Rail & Transit

Because Aztec Code requires zero quiet zone margins, it can be printed right up to the edge of boarding passes, tickets, or smartphone screens without sacrificing decodability.

PDF417 (Portable Data File)

ISO/IEC 15438 • Stacked 2D Linear
⚡ Generate in Studio

PDF417 consists of stacked rows of 1D linear codes. Each codeword is 17 modules wide and composed of 4 bars and 4 spaces. It can encode large text payloads, binary files, and biometric fingerprints directly on card stock.

Standard Ratio
2.5:1 to 3:1 (Wide Rectangle)
Max Data Capacity
1,850 Alphanumeric Chars
Error Correction
Levels 0 to 8 (Reed-Solomon)
Primary Use
Driver Licenses (AAMVA), FedEx/USPS

Code 128 & GS1-128

ISO/IEC 15417 • 1D High-Density Alphanumeric
⚡ Generate in Studio

Code 128 is the highest-density 1D linear symbology in commercial use. It encodes the entire 128-character ASCII table using three dynamic subsets:

  • Subset A: Uppercase letters, digits, control characters, ASCII 00-95.
  • Subset B: Uppercase and lowercase letters, digits, and ASCII punctuation 32-127.
  • Subset C: Pairs of numeric digits 00-99 encoded into single bar patterns (double density).
Engine Switching
Auto-Switching A/B/C
Check Digit
Modulo 103 (Auto-Calculated)
Primary Use
Supply Chain, Warehouse, Logistics
Quiet Zone
10x Narrow Bar Width

EAN-13 (International Retail)

ISO/IEC 15420 • GS1 GTIN-13 Point of Sale
⚡ Generate in Studio

EAN-13 (European / International Article Number) is the global standard for retail point-of-sale scanning everywhere outside North America. It encodes a 13-digit sequence: Country Prefix (2-3 digits), Manufacturer Code, Product Code, and a final Modulo 10 Check Digit.

Digit Length
12 or 13 Numeric Digits
Checksum Math
GS1 Modulo 10 (Weight 3/1)
Auto-Correction
Auto-Appends Missing 13th Digit
Licensing Note
Requires GS1 Registration for Retail

UPC-A (Universal Product Code)

GS1 GTIN-12 • North American Point of Sale
⚡ Generate in Studio

UPC-A is the standard retail barcode used throughout the United States and Canada. It encodes exactly 12 numeric digits (or 11 data digits + 1 Modulo 10 check digit). An EAN-13 barcode with a leading zero ('0') is mathematically identical to a 12-digit UPC-A barcode.

📦

ITF-14 (Interleaved 2 of 5)

GS1 GTIN-14 • Master Shipping Container
⚡ Generate in Studio

ITF-14 encodes 14 numeric digits and is printed with heavy black horizontal borders called Bearer Bars. These bearer bars suppress plate-spread and stop misreads caused when a handheld laser scanner skims across the edge of corrugated cardboard packaging.

🏢 When Do You Legally Need GS1 Registration?

🔴 GS1 Registration IS Required:

  • Selling consumer packaged goods (CPG) in open retail stores (Walmart, Target, Tesco, Carrefour).
  • Registering brands on Amazon Brand Registry or Google Shopping feeds (GS1 GEPIR database validation).
  • Commercial healthcare products subject to FDA Unique Device Identification (UDI) or EU FMD.
  • Exporting goods internationally through multi-carrier customs brokers.

🟢 100% FREE (No GS1 Fees Required):

  • Internal warehouse bin, shelf, aisle, and pallet rack identification (Code 128 / Code 39).
  • Enterprise asset tracking (laptops, office chairs, machinery, tools).
  • Private retail stores operating their own POS software: use EAN-13 prefixes 200–299 or UPC-A prefix 2 (restricted circulation).
  • All QR Codes: Wi-Fi setup, vCard contacts, URLs, SMS dialers, cryptocurrency cold wallets.

🧮 Checksum Algorithms & Verification Mathematics

Checksums ensure that dirty scanner glass, poor lighting, or operator keyboard errors cannot introduce corrupt product IDs into ERP or POS databases:

GS1 Modulo-10 Check Digit Formula (Used by EAN-13, UPC-A, ITF-14, SSCC-18)
// Step 1: Starting from right-to-left before check digit, alternate multiplying by 3 and 1.
// Step 2: Sum all weighted products.
// Step 3: Check Digit = (10 - (Sum % 10)) % 10.

function calculateMod10(digits) {
  let sum = 0;
  const len = digits.length;
  for (let i = 0; i < len; i++) {
    const digit = parseInt(digits[len - 1 - i], 10);
    sum += (i % 2 === 0) ? digit * 3 : digit * 1;
  }
  return (10 - (sum % 10)) % 10;
}

Code 128 Modulo-103: The check character is calculated by taking the Start code value, adding the product of each character's value multiplied by its position index (1, 2, 3...), and taking the modulo 103 remainder.
2D Reed-Solomon Error Correction: Implemented over Galois Fields (GF(256)) to compute generator polynomials. If a barcode module is physically obliterated or torn, linear feedback shift register decoding mathematically reconstructs the original payload.

📐 Prepress Print Quality, Quiet Zones & Avery Tolerances

Mandatory Quiet Zones

• Code 128: Minimum 10X module width left & right.
• EAN-13: 3.63mm left, 2.31mm right.
• QR Code: 4 modules on all 4 sides.
• Aztec Code: 0 modules (zero quiet zone required).

Print Contrast & Wavelength

Laser scanners emit red light (630–670nm). Bars must absorb red (black, dark blue). Backgrounds must reflect red (white, cream). Never print red bars on white paper or black bars on green!

Avery Label Sheet Tolerances

Desktop inkjet/laser sheet feeders experience 0.5mm–1.5mm mechanical drift. Our Avery generator applies centered safe zones to prevent bar clipping on die-cut adhesive edges.
