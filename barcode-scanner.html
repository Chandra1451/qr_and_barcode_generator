Free Online Barcode & QR Code Scanner

Read a QR code or barcode from a photo, a screenshot or your camera. Everything is decoded on your own device: your images and their contents are never uploaded.

Your browser will ask for permission. The camera stops as soon as a code is found.

How to scan a barcode or QR code online

  1. Add the code: choose or drop a photo or screenshot, paste an image you copied, or tap Use camera.
  2. Read the result: the code type (for example QR Code or EAN-13) and its contents appear straight away. Several codes in one image are all listed.
  3. Use it: copy the text, open a website link after checking its address, or create an editable copy of the code in our free Studio.

Supported barcode types

2D codes: QR Code, Micro QR, rMQR, Data Matrix, Aztec, PDF417 and MaxiCode.

1D barcodes: EAN-13, EAN-8, UPC-A, UPC-E, ISBN (Bookland EAN), Code 128 and GS1-128, Code 39, Code 93, Codabar, ITF / ITF-14 and GS1 DataBar.

Stay safe with QR codes

Fake QR codes stuck over real ones (sometimes called quishing) are a common way to send people to phishing sites or fake payment pages. This scanner never opens a link by itself: it shows you the full address and the real website name first. Before opening a link or paying, check that the address is the one you expect, and never enter passwords or card details on a page you reached from a code you don’t trust.

Frequently asked questions

Is it safe to scan a code here? Are my images uploaded?

Your images are never uploaded. The picture is decoded by your own browser, and the reader runs locally as WebAssembly. Photos, camera frames and the decoded text are not sent to our server, not stored, and not shared with analytics or advertising partners.

Which barcode types can it read?

QR Code, Micro QR, rMQR, Data Matrix, Aztec, PDF417 and MaxiCode, plus the common 1D barcodes: EAN-13, EAN-8, UPC-A, UPC-E, Code 128 (including GS1-128), Code 39, Code 93, Codabar, ITF / ITF-14 and GS1 DataBar.

Why is no code found in my photo?

Use a sharp, well-lit photo in which the whole code is visible, including the blank margin around it. Avoid strong glare and very steep angles. Screenshots of on-screen codes work best.

Can I scan with my phone camera?

Yes. Tap “Use camera” and allow camera access when your browser asks. The camera is only used while scanning, stops as soon as a code is found or you leave the page, and can be turned off with the Stop button at any time.

Is scanning free?

Yes. The scanner is free for personal and commercial use, with no sign-up and no limit on the number of scans.
